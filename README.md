# HR Analytics Dashboard | Power BI

An interactive **Human Resources analytics** project built in Microsoft Power BI. The report explores employee attendance patterns through a dashboard experience with period-based filtering, supported by Power Query preparation and project documentation.

## Project overview

This project demonstrates how HR-related data can be transformed into an interactive report to support workforce monitoring and people-operations analysis.

### What the report covers

- Employee attendance reporting and KPI-focused visuals
- Month and period-based filtering to explore attendance patterns
- Data preparation and transformation using Power Query
- Interactive report navigation and visual analysis
- Supporting Power Query documentation and dashboard exports

## Open the project

1. Download or clone this repository.
2. Install and open **Power BI Desktop**.
3. Open `HR_DASHBOARD_PowerBI Project.pbix`.
4. If Power BI prompts for a missing source, update the source path or reconnect the required data before refreshing.
